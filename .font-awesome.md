# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Kit embed (JS loader). The Kit's technology is set to Web Fonts.
- **Version:** 7.3.1
- **License:** Pro
- **Kit ID:** `c11880975e` ("Continia Icons 2026"). Use it as `--kit-token` with the `fa` CLI, for example `fa kit icon <name> --kit-token c11880975e` or `fa search --kit-token c11880975e --query <term>`.
- **Kit Revision:** 64
- **Embed:** `<script src="https://kit.fontawesome.com/c11880975e.js" crossorigin="anonymous"></script>` in the `<head>` of `index.html`
- **Families:** classic (solid, regular, light). The Kit has no brands, duotone, sharp or thin.
- **Custom icons:** 29 uploads, used with the `fa-kit` prefix (for example `fa-kit fa-document-capture-solution-dc-icon`).

## Defaults

- **Style:** light
- **Family:** classic

## Import Pattern

This is a static HTML site with no build step. Icons are `<i>` elements with class names:

- Standard icon: `<i class="fa-light fa-download" aria-hidden="true"></i>`
- Continia custom icon: `<i class="fa-kit fa-banking-solution-cb-icon" aria-hidden="true"></i>`
- Search results in `Assets/js/hub.js` build their icons as HTML strings, for example `'<i class="fa-light fa-bookmark" aria-hidden="true"></i>'`.

## Conventions

These are the Continia icon rules. The full version is in the Icons chapter of `index.html` (`#icons`).

- Use **classic light** on web and product UI. Solid is allowed only on other surfaces such as decks and print, with one style per surface. **Never use regular**, even though the Kit includes it.
- Not allowed: duotone, sharp, thin, multicolor, hand-drawn SVG icons, other icon libraries, emoji.
- For a Continia solution or module, always use the `fa-kit` icon instead of a generic one. Give `fa-document-capture-solution-dc-icon` `transform: scale(1.18)` (class `.icon-dc`) when it sits next to other solution icons.
- Colors are Tech Blue `#052975`, Innovation Blue `#8FF8FF`, Light Blue `#DEF5FF` or White only.
  - On white or Light Blue grounds, use a Tech Blue icon.
  - On Tech Blue, use a White or Innovation Blue icon.
  - Status icons are the one exception. They may use semantic colors (Rejection Red `#c6283c`, Smart Green, Performance Purple), always paired with a word.
- Place icons free on the background, or on a solid tile: `.icon-tile`, 48 × 48 px, 12 px radius, Tech Blue with a white icon. On a Tech Blue card, use `.icon-tile--brand` (12% white).
- Never put an icon inside a quarter circle or half circle. Never put an icon tile, button, chip or card on the gradient.
- Callouts are `.note`: a bordered card with a `fa-light` icon that carries the meaning. Never use a colored left-border bar.
- Feature-list bullets use `fa-light fa-check` or `fa-light fa-circle-check`.
- Decorative icons get `aria-hidden="true"`. Icon-only buttons need an `aria-label`. Touch targets are at least 44 × 44 px.
- Social logos should use `fa-brands`, but the Kit does not include brands yet, so those icons render blank. Enable Brands in the Kit settings before using them.
